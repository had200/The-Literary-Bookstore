## ✦ About the Project

**The Literary Bookstore** is a mobile application developed with Flutter, Dart, PHP, and MySQL.

Designed for book lovers, it offers a simple and enjoyable way to discover books, explore categories, search for titles, and manage a personal shopping experience.

---

## ✦ Features

- 📖 Browse and discover books.
- 🔍 Search for books and explore categories.
- 📚 View detailed book information.
- ♥ Manage favorite books.
- 🛒 Add books to the shopping cart.
- 🌙 Light and dark themes.
- 👤 User profile management.
- ⚙️ Admin dashboard for managing books and users.
