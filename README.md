## 𓂃 About the Project

**The Literary Bookstore** is a digital bookstore application designed to bring the experience of discovering and exploring books into a modern mobile environment.

Built with **Flutter**, the application combines an elegant literary-inspired interface with practical bookstore functionalities, allowing readers to explore different genres, discover books, manage favorites, and organize their shopping cart.

Beyond the reader experience, the platform includes an administrative space designed to simplify bookstore management.

> Our vision is simple: to create more than a bookstore — a digital space where knowledge meets imagination.

## ✦ Features & Experiences

### 01 — Discover Your Next Story
- Explore literary categories.
- Browse an organized book catalog.
- Search for books.

- Add new books.
- Update book information.

- Search and manage the catalog.
- Manage registered users.

## 🏛️ System Architecture

The application follows a three-layer architecture:

```text
       ┌─────────────────────────────┐
       │       PRESENTATION          │
       │                             │
       │       Flutter / Dart        │
       │                             │
       │  UI · Navigation · Themes   │
       └──────────────┬──────────────┘
                      │
                 HTTP Requests
                      │
                      ▼
       ┌─────────────────────────────┐
       │       APPLICATION           │
       │                             │
       │           PHP API           │
       │                             │
       │   Business Logic · CRUD     │
       └──────────────┬──────────────┘
                      │
                 SQL Queries
                      │
                      ▼
       ┌─────────────────────────────┐
       │          DATABASE           │
       │                             │
       │            MySQL            │
       │                             │
       │  Books · Users · Data       │
       └─────────────────────────────┘
```

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio
- PHP
- MySQL
- XAMPP or another local PHP/MySQL environment

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/The-Literary-Bookstore.git
```

**2. Navigate to the project**

```bash
cd The-Literary-Bookstore
```

**3. Install Flutter dependencies**

```bash
flutter pub get
```

**4. Configure the backend**

- Set up your MySQL database.
- Import the project database.
- Configure the PHP backend.
- Update the API base URL according to your environment.

**5. Run the application**

```bash
flutter run
```
